# 视频抠像工具 · Clipgen

把一段人物视频转成**带透明通道的逐帧素材包**（WebP + alpha），用来做桌面特效、直播叠加，或者丢进剪辑软件。

给 [英雄登场](https://github.com/RealKilogram/hero-arrival) 配套写的小工具，但素材包是通用的：任何能吃 PNG 序列的东西都能用。

---

## 输出长什么样

跑完之后得到一个文件夹：

```
我的素材/
  clip.json          { "name": "我的素材", "count": 120, "fps": 60, "width": 1920, "height": 1080 }
  frames/
    000.webp         带透明通道的帧，连续编号
    001.webp
    ...
  sounds/            空目录，自己往里放 mp3/wav/ogg，播放时随机抽一个
```

`count` 是帧数，`fps` 是播放帧率，两者一起决定这段素材多长。

## 需要什么

| 依赖 | 说明 |
| --- | --- |
| Python 3.9+ | 从 https://www.python.org/downloads/ 装，**记得勾 "Add Python to PATH"** |
| Python 包 | `pip install -r requirements.txt`（numpy / opencv-python-headless / pillow / onnxruntime） |
| `ffmpeg.exe` | 解码视频用。放本目录下，或者用系统 PATH 里的（加 `--ffmpeg ffmpeg`） |
| `rmbg14.onnx` | 抠像模型，**168MB，不在仓库里**，见下 |

### 下载模型

HuggingFace 仓库 [`briaai/RMBG-1.4`](https://huggingface.co/briaai/RMBG-1.4) 里的 `onnx/model.onnx`，下载后重命名成 `rmbg14.onnx` 放在本目录。

国内打不开 huggingface 的话，把域名换成镜像：

```
https://hf-mirror.com/briaai/RMBG-1.4/resolve/main/onnx/model.onnx
```

> ⚠️ RMBG-1.4 是 **非商业许可**（bria-rmbg-1.4 license）。自己玩、做个人视频没问题；要商用请换成 Apache-2.0 的 ISNet 之类，改 `--model` 指过去即可（输入格式是 1024×1024、归一化到 [-0.5, 0.5]）。

## 用法

### 图形界面（推荐）

**Windows**：双击 `抠像工具.bat`，浏览器会自动打开 `http://127.0.0.1:17331/`。

界面上：

1. 把视频拖进虚线框，或点「点击选择文件」
2. 填素材名字，选帧率（30 或 60）
3. 选**导出到哪儿**：留空就导出到当前目录的 `out/<名字>/`；也可以填任意路径（支持相对路径和环境变量，或点「浏览…」在网页里点目录树）
4. 点「开始抠像」，进度条和日志实时滚
5. 跑一半不想做了，点红色「终止」，然后选择要不要删掉已经生成的半成品

界面底部有「环境检查」，缺 Python 包、缺模型、缺 ffmpeg 都会标红告诉你怎么办。

### 命令行

```bash
python clipgen.py -i 我的视频.mp4 -o D:\clips\my-clip --name "我的角色" --fps 60
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-i` / `--input` | 必填 | 输入视频（mp4 / mov / mkv） |
| `-o` / `--output` | 必填 | 输出素材包目录 |
| `--name` | 输出目录名 | 显示名，写进 clip.json |
| `--fps` | 30 | 抽帧帧率。想要丝滑就 60，体积翻倍 |
| `--quality` | 88 | WebP 质量 1–100。88 大概 300KB/帧（2560×1400） |
| `--temporal` | 5 | 时间中值窗口，压掉逐帧抠像的闪烁；设 1 关闭 |
| `--smooth` | 0.15 | 与上一帧的混合系数，0 关闭 |
| `--boost` | on | 额外跑一次提亮图取较大遮罩，救暗部主体；代价是推理时间翻倍 |
| `--threads` | 4 | onnxruntime 线程数 |
| `--model` | `rmbg14.onnx` | 模型路径 |
| `--ffmpeg` | `ffmpeg.exe` | ffmpeg 路径 |

### 去闪烁（单独跑）

已经生成的素材包如果还有点闪，可以只对 alpha 做时间中值，不重新抠：

```bash
python denoise_clip.py 素材包目录 --half 2
```

它会把原帧备份到 `frames_backup/`，然后重写 `frames/`。

## 处理流程

1. **解码** — ffmpeg 按 `--fps` 抽帧，转成 RGB 原始画面
2. **推理** — 每帧缩到 1024×1024 送进 RMBG-1.4，拿到 0–1 的软遮罩
3. **精修** — 用原图做引导滤波（guided filter），把 1024 的糊边对齐到真实边缘
4. **提亮再推理** — `--boost on` 时把画面过一遍 CLAHE 提亮再推理一次，两张遮罩取较大值。**这一步是为了救暗部主体**：深色头发、背光人脸这类，模型在原图上容易判成背景
5. **时间中值** — 取前后几帧遮罩的中位数，压掉逐帧抖动（`--temporal`）
6. **去绿边** — 把绿色通道压到不超过红蓝的最大值，处理绿幕素材的溢色
7. **编码** — 存成带 alpha 的 WebP，写 `clip.json`

## 效果说明

**通用模型不是万能的**，同一段视频里不同镜头的效果可能差很多：

| 情况 | 结果 |
| --- | --- |
| 主体清晰、背景干净、光照正常 | 很好，边缘干净 |
| 人物在画面里很小（远景） | 遮罩会偏小，可能带上一点背景 |
| 主体很暗、背景很亮 | 容易漏判，开 `--boost` 能救回来一部分 |
| 大量半透明光效 / 粒子 | 光晕会被切掉一部分，或者整片带上低透明度 |
| 人物本身半透明（化光、残影） | **基本抠不出来**，模型认不出人 |
| 画面里有水印 / 台标 | 需要另外裁掉或者在后期屏蔽 |

给一条经验：**先用默认参数跑 10 秒的片段看看**，满意了再跑整段。整段跑完发现不行，重来一遍很费时间（1080p 大约 1.5–2 秒/帧）。

## 常见问题

**Q: 双击 bat 一闪而过 / 提示没找到 Python**
说明没装 Python 或者没勾 "Add Python to PATH"。重装一次，安装第一页勾上那个复选框。

**Q: 提示 `Permission denied` 写不进目标目录**
换一个目录试试，或者确认目标目录没有只读属性。Windows 上如果程序本身被打上了低完整性标签，也会写不进普通目录 —— 这种情况把整个工具文件夹用**资源管理器**重新复制一份到别处，从新位置启动。

**Q: 抠出来的边缘有白边 / 黑边**
半透明边缘会混进背景颜色。降低 `--quality` 不会改善，可以提高 `--temporal` 让边缘更稳，或者在后期软件里做一点边缘收缩（choke）。

**Q: 素材包太大**
降 `--fps` 到 30，或者 `--quality` 到 80。一个 60 帧 2560×1400 的包，quality 88 大约 17MB。

**Q: 支持绿幕素材吗**
支持，但绿幕其实用色度键（chroma key）更快更干净。这个工具走的是 AI 分割路线，适合**没有绿幕、背景复杂**的素材。
